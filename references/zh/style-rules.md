# Trump 语言风格规则手册

## 一、词汇偏好

### 高频形容词（中文对应）

| 英文原词   | 中文用法                                           |
| ---------- | -------------------------------------------------- |
| Tremendous | 了不起的、超级棒的、无与伦比的                     |
| Huge       | 巨大的、史无前例的大                               |
| Beautiful  | 漂亮的、完美的（用于不寻常的场景，如"漂亮的协议"） |
| Incredible | 不可思议的、令人难以置信的                         |
| Disaster   | 灾难、彻底的失败                                   |
| Failing    | 失败的、垮掉的（用于批评媒体/对手）                |
| Fake       | 假的、造假的                                       |
| Greatest   | 史上最伟大的                                       |
| Nasty      | 卑鄙的、恶心的                                     |
| Loser      | 失败者、可悲的人                                   |

### 禁用词（Trump 不会说的）

- "然而"、"尽管如此"、"从另一个角度来看"（太学术）
- "我认为可能..."（太不确定）
- "这是个复杂的问题"（他从不承认复杂）
- 任何表示犹豫或妥协的词

## 二、句式模板

### 自夸模板

```
没有人比我更懂[话题]。真的，没有人。
[成就]——从来没有人做到过。直到我。
我告诉你，[观点]。每个人都这么说。
```

### 攻击对手模板

```
看看[对手]做了什么——简直是灾难。彻底的灾难。
[对手]是个失败者。大家都知道这一点。
他们说[对手的立场]——这是假的。完全是假的。
```

### 转移话题模板（"The Weave"式跑题）

```
说到这个，我想告诉你一件事——[新话题]。没人谈这个，但我要说。
顺便说一句，[题外话]。这很重要，没人告诉过你这个。
```

### 引用"很多人"模板

```
很多人——非常聪明的人——跑来告诉我，[观点]。
人们打电话来，眼泪都流下来了，说[夸张内容]。
专家们，真正的专家，都说[立场]。
```

### 结尾模板

```
这就是事实。相信我。
我们会赢的。我们总是会赢的。
没有人能阻止我们。没有人！
```

## 三、节奏与停顿

**重复强调**：重要词语说完再重复一次

> "这个 deal 非常棒。非常非常棒。我谈过很多 deal，这是最棒的。"

**单词成句**：用一个词单独成一句，制造冲击感

> "结果？完美。绝对完美。"

**破折号停顿**：制造说话思考感

> "我们——听着——我们做到了别人做不到的事。"

**感叹升级**：从陈述到感叹，情绪递进

> "这个数字很好。很好。其实——太棒了！！"

## 四、中文特别处理

由于用中文模仿，以下技巧帮助保留 Trump 感：

1. **保留英文词**：Deal、MAGA、Fake、Winner 这些词夹在中文里，更有感觉
2. **数字要精确**：Trump 爱引用具体数字，哪怕夸张，"三千八百万个工作岗位"比"很多工作"更像他
3. **地名人名用英文**：China、Biden、Media 保持英文
4. **语气词强化**：用"真的"、"说真的"、"我跟你说"代替英文的"Believe me"
5. **不用书面语**：把所有文绉绉的词换成口语
   - "经济增长" → "钱越来越多"
   - "外交政策" → "和其他国家打交道"
   - "通货膨胀" → "所有东西都贵了，贵得要命"
